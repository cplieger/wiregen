# Options and fields

This page lists every option `Registry.Generate` takes, every field of the `Registry`, and the helper types, for a developer writing a generator program. The registry holds what to generate, and the options say how and where to write it.

## Options

Options apply in the order you pass them, and a later option for the same setting wins.

| Option | Default | Description |
| --- | --- | --- |
| `WithTSDir(dir string)` | required | Directory every TypeScript file is written under. Every other TypeScript file option names a path inside it, subdirectories allowed. An absolute path or one leaving it is refused, and the files are written through an `os.Root` there, so a symlink cannot redirect one outside. |
| `WithValidatorsFile(name string)` | `"validators.gen.ts"` | Path of the validators module inside the TS directory, written on every run. |
| `WithValidatorsImport(module string)` | the relative specifier from each importing file | Specifier every generated module imports the validators module by. Set it only when a bundler alias reaches the module. |
| `WithTypesImportPath(module string)` | the relative specifier from each importing file | Specifier the decoders, events module, client and arbitraries import the types file by. |
| `WithTransportImport(module string)` | required with `Endpoints` | Specifier of your transport module, which the generated client calls. See [Typed HTTP client](http-client.md#transport-module). |
| `WithClientFilename(name string)` | `"client.gen.ts"` | Name of the generated client file. |
| `WithFilenames(names Filenames)` | `types.gen.ts`, `decoders.gen.ts`, `events.gen.ts`, `constants.gen.ts` | Renames those four files. An empty field keeps that file's default. |
| `WithHeaderComment(comment string)` | `// Code generated by wiregen. DO NOT EDIT.` | Comment at the top of every generated TypeScript file. |
| `WithArbitrariesFile(name string)` | _(unset)_ | Writes the fast-check arbitraries module at this path. See [Property-test arbitraries](arbitraries.md). |
| `WithArbitrariesImport(module string)` | `"fast-check"` | Specifier the arbitraries module imports fast-check's default export from. |
| `WithOpenAPIFiles(paths ...string)` | _(unset)_ | Writes the OpenAPI 3.1 document at each path, relative to the working directory and outside the TS directory's confinement, in the same pass as the TypeScript files. `Registry.OpenAPI` must name a title and a version. |
| `WithRequireJSONTags()` | off | Makes an exported field without a `json` tag a generation error naming its path. Without it such a field takes its Go name, as `encoding/json` gives it. |

The generated files import each other by their paths relative to one another, so a module in a subdirectory imports `../types.gen.js`. Two outputs that are one file, however spelled, through a symlink or differing only in case, are refused before anything is written. The final extension is rewritten the way TypeScript rewrites it, so `.mts` becomes `.mjs`, `.cts` becomes `.cjs` and any other extension becomes `.js`.

## Registry fields

| Field | Type | Description |
| --- | --- | --- |
| `Types` | `[]WireType` | Structs to generate interfaces, decoders and schemas for. A type an endpoint, event, union or `ErrorEnvelope` names joins them without being listed. |
| `Enums` | `[]EnumRef` | Enums, each registered with `StringEnum[T]()` or `TextEnum[T]()`. See [Type mapping](type-mapping.md#enums). |
| `Unions` | `[]Union` | Registered structs tagged by one field. See [Type mapping](type-mapping.md#unions). |
| `Mappings` | `map[string]Mapping` | The consumer's own TypeScript type, decoder and schema for a Go type, keyed by full `importpath.Type`. See [Type mapping](type-mapping.md#mappings). |
| `Endpoints` | `[]Endpoint` | The HTTP endpoint table, from which the client and the document's paths are generated. See [Typed HTTP client](http-client.md). |
| `Events` | `[]Event` | The named frames of the event-stream endpoints. A non-empty list writes the events module. |
| `ErrorEnvelope` | `WireType` | The JSON body of every error response. Zero when none is declared. |
| `OpenAPI` | `OpenAPIInfo` | The document's title, version, description and security schemes. |
| `Constants` | `[]WireConst` | Integer constants to write into the constants file. |
| `TSNameOverride` | `map[string]string` | TypeScript name for a struct, keyed by Go name. |
| `EnumTSName` | `map[string]string` | TypeScript name for an enum, keyed by Go name. |
| `PathNameOverride` | `map[string]string` | Path segment a decoder reports in its errors for a type, keyed by TypeScript name. |

Types and enums are keyed by bare Go name, so one name registered from two packages is refused. Rename one, or override its TypeScript name. `Generate` reads the registry and never modifies it, so one `Registry` can be generated more than once.

## Helper types

```go
// WireType names a registered Go type by package path and name.
type WireType struct {
    PkgPath string
    Name    string
}

// TypeRef names T; TypeOf names a reflect.Type. An unnamed type yields a
// WireType Generate refuses.
func TypeRef[T any]() WireType
func TypeOf(t reflect.Type) WireType

// EnumRef registers an enum by its type; build it with StringEnum or TextEnum.
type EnumRef struct {
    Wire func(value uint64) (string, error) // nil for a string enum
    Type WireType
}
func StringEnum[T ~string]() EnumRef
func TextEnum[T interface{ ~uint8; encoding.TextMarshaler }]() EnumRef

// Union tags Type by its Tag field; each Cases key is a tag value listing the
// other fields that case allows, all by wire name.
type Union struct {
    Cases map[string][]string
    Type  WireType
    Tag   string
}

// Mapping is a Go type's wire form, written by the consumer.
type Mapping struct {
    Schema  map[string]any // required when OpenAPI files are written
    TS      string
    Decoder string // called as (obj, key, path); empty casts unchecked
}

// Event is one named frame of an event-stream endpoint.
type Event struct {
    Data WireType
    Name string
}

type OpenAPIInfo struct {
    SecuritySchemes map[string]SecurityScheme
    Title, Version, Description string
}

// SecurityScheme: Type "http" with Scheme, "apiKey" with In (header, query
// or cookie) and Name, or "mutualTLS".
type SecurityScheme struct {
    Type, Scheme, In, Name, Description string
}

type WireConst struct {
    TSName string
    Value  int
}

// Filenames renames four output files. An empty field keeps its default.
type Filenames struct {
    Types     string
    Decoders  string
    Events    string
    Constants string
}
```

`Endpoint`, `Kind`, `ErrorRef` and `Header` are on the [Typed HTTP client](http-client.md#the-endpoint-table) page.

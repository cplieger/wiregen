# Options and fields

This page lists every option `NewRegistry` takes, every exported field on the `Registry`, and the helper types, for a developer writing a generator program. Options set how the output is written. The exported fields hold what to generate, and you assign them after `NewRegistry` returns.

## Options

Options apply in the order you pass them, and a later option for the same setting wins.

| Option | Default | Description |
| --- | --- | --- |
| `WithValidatorsImport(v string)` | required | Import specifier the decoders use for the validators module, such as `"./validators.js"`. |
| `WithValidatorsFile(v string)` | _(unset)_ | Writes the validators module at this path, relative to `outDir`, on every run. The path may leave `outDir`, such as `"../validators.ts"`. |
| `WithBusImport(v string)` | required with `SSEEvents`, unless self-contained | Import specifier of your bus module, which exports the register function. |
| `WithSelfContainedRegistry(v bool)` | `false` | Writes a `Map`-based registry that exports `getSSEDecoder(eventType)`, instead of importing a bus module. |
| `WithRegisterFuncName(v string)` | `"registerSSEDecoder"` | Function the registry imports from the bus module. |
| `WithRegistryFuncName(v string)` | `"registerAllSSEDecoders"` | Function the registry file exports. |
| `WithTransportImport(v string)` | required with `Endpoints` | Import specifier of your transport module, which the generated client calls. |
| `WithClientFilename(v string)` | `"client.gen.ts"` | Name of the generated client file. |
| `WithFilenames(names Filenames)` | `types.gen.ts`, `decoders.gen.ts`, `registry.gen.ts`, `constants.gen.ts` | Renames the four core files. An empty field keeps that file's default name. |
| `WithTypesImportPath(v string)` | derived from the types file name, `"./types.gen.js"` | Import specifier the decoders use for the types file. Set it when the types file lives outside `outDir`. |
| `WithHeaderComment(v string)` | `// CODE-GENERATED by wiregen, DO NOT EDIT.` | Comment at the top of every generated file, the validators module included. |
| `WithArbitrariesFile(v string)` | _(unset)_ | Writes the fast-check arbitraries module at this path, relative to `outDir`, on every run. |
| `WithArbitrariesImport(v string)` | `"fast-check"` | Import specifier the arbitraries module takes fast-check from, as the default export `fc`. |

The generated files import each other by names derived from these settings. The final extension is rewritten the way TypeScript rewrites it, so `.mts` becomes `.mjs`, `.cts` becomes `.cjs` and any other extension becomes `.js`.

## Registry fields

| Field | Type | Description |
| --- | --- | --- |
| `Types` | `[]WireType` | Go types to generate interfaces and decoders for. Register each with `TypeRef[T]()`. |
| `PackagePaths` | `[]string` | Import paths to load and parse. Optional, derived from the packages of `Types`. Set it only to load extra packages. |
| `Enums` | `map[string]EnumDef` | Named string enums, keyed by Go type name. `Values` is optional (see below). |
| `EnumTSName` | `map[string]string` | TypeScript name for an enum, keyed by Go name. |
| `TSNameOverride` | `map[string]string` | TypeScript interface name for a struct, keyed by Go name. |
| `PathNameOverride` | `map[string]string` | Path segment the decoder reports in errors for a type, keyed by TypeScript name. |
| `TypeMappings` | `map[string]string` | TypeScript type for a Go type, keyed by full `importpath.Type`, such as `".../uuid.UUID"` to `"string"`. |
| `DecoderMappings` | `map[string]string` | Decoder helper for a Go type, same key. The decoder calls it instead of casting the value. |
| `DiscriminatorMap` | `map[string]map[string]string` | For each union, the discriminator value to variant decoder map. Setting it emits the union's runtime decoders. |
| `SSEEvents` | `[]SSERegEntry` | SSE event names and the registered type each one carries. |
| `Constants` | `[]WireConst` | Integer constants to write into the constants file. |
| `Endpoints` | `[]Endpoint` | HTTP endpoint table. A non-empty table adds the generated client, see [Typed HTTP client](http-client.md). |

An enum with no `Values` takes them from the `const` block of its named type, in source order, read only from the registered packages, so a same-named type in a dependency cannot add values. Explicit `Values` win. Set them when a value has no named constant, or when the order you want differs from the source.

A `TypeMappings` or `DecoderMappings` key may name a type alias or the type it resolves to. [Type mapping](type-mapping.md#type-and-decoder-mappings) explains why both spellings work.

A `Registry` can run `Generate` more than once. Its derived state is rebuilt on every call, so types appended between two calls are picked up.

## Helper types

```go
// WireType identifies a registered Go type by package path and name.
type WireType struct {
    PkgPath string
    Name    string
}

// TypeRef registers a type by identity. It uses reflect only for the
// {PkgPath, Name} pair; the fields are read from source.
func TypeRef[T any]() WireType

type WireConst struct {
    TSName string
    Value  int
}

type EnumDef struct{ Values []string }

type UnionDef struct {
    Discriminator string
    Variants      []string
}

type SSERegEntry struct {
    EventType string
    TypeName  string
}

// Filenames renames the four core output files. An empty field keeps
// that file's default name.
type Filenames struct {
    Types     string
    Decoders  string
    Registry  string
    Constants string
}
```
